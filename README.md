## 腾讯云快照怎么计费？

快照按“快照容量 × 地域单价 × 时长”计费，按小时结算，按月折算。80GB 免费额度先从总容量里扣，扣完再乘单价。

具体规则不复杂，但有几个口径容易看错：

- 计费项只有快照容量，不按云硬盘总容量收费。一块 500GB 的盘只用了 100GB，首份快照按 100GB 算，不是 500GB。
- 第一份快照是全量快照，容量等于云硬盘当时的已使用容量。官方给的例子是 200GB 的盘已用 122GB，首份快照就是 122GB。
- 后续快照按块级别记录发生变化的数据，容量会继续累加。数据改动越频繁，快照总容量涨得越快。
- 计费周期按小时，价目表里的月单价是折算值。短时间开几天快照，按小时算；长期保留，按月估算更直观。
- 价格跟地域走。同一个账号在不同地域的快照，单价不同。

公式可以写成：

**月费用 ≈（快照总容量 − 80GB）× 地域月单价**

如果快照总容量不到 80GB，容量费用就是 0。注意这 80GB 是额度，算的是总快照容量，不是每块盘各送 80GB。

## 为什么实际账单可能比你算的高？

常见原因有三个：快照容量比文件系统里看到的大、云硬盘释放后快照还在、自动快照按策略继续保留。

1. **快照容量通常大于文件系统统计。** 快照是块级别备份，底层元数据、删除数据时改动过的块都会被记录。你在系统里看到“已用 100GB”，快照容量可能更高。
2. **释放云硬盘不会自动删除快照。** 官方文档明确，释放云硬盘后本地快照不会随之释放，需要去控制台或 API 手动删除。不删，继续计费。
3. **自动快照不随实例到期或云硬盘释放而删除。** 它遵循定期快照策略里的保留时间。实例没了，策略还在，快照也还在。
4. **欠费不会立刻删快照，但会隔离。** 账号欠费后快照进入“已隔离”状态，保留 30 天；30 天内没充值到余额大于等于 0，到期后账号下所有快照（镜像快照除外）会被删除。这更像数据风险，值得单独留意。

还有一条限制：快照不能下载或导出到本地，也不能直接跨账号迁移。把它当“云硬盘的后悔药”可以，当离线归档不合适。真要跨账号，得把快照做成镜像再共享。

## 把快照费用压下来的几个动作

最有效的三件事：用满 80GB 免费额度、删掉不需要的快照、按数据重要性分层设置策略。

2. **释放云硬盘后去删快照。** 这是最容易漏的一笔，尤其是换机、重装、项目结束后。
3. **定期快照策略按恢复点需求设保留时间。** 一块云硬盘只能设一个自动快照策略，所以策略要按盘的重要性分，不要所有盘共用一个大而全的策略。
4. **高频快照只给核心数据盘。** 系统盘变化少，低频快照通常够用；数据库盘、文件盘才是容量增长的主力。
5. **业务低峰期打快照。** 制作快照会占用云硬盘少量 I/O，避开高峰不影响计费，但能少影响业务。

## 常见问题

**腾讯云快照有免费额度吗？**

**快照按云硬盘总容量收费吗？**

不按。第一份全量快照按云硬盘已使用容量算，后续快照按变化的数据块累计。

**删除云硬盘后，快照还会收费吗？**

会。释放云硬盘不会删除快照，需要手动清理，否则继续计费。

**快照能下载到本地吗？**

不能。快照不能下载或导出，也不能直接跨账号迁移；需要跨账号可以制作镜像共享。

**账号欠费后快照会马上删除吗？**

不会立刻删。快照进入隔离状态保留 30 天，期间充值到余额大于等于 0 可以恢复；到期未处理会被删除（镜像快照除外）。

**本地盘能创建快照吗？**

不支持。本地盘需要在应用层做数据冗余，或者用部署集提高可用性。

**一块云硬盘能设几个自动快照策略？**

一个。手动快照和定期快照在使用上没有冲突，但同时创建时可能需要等待。

**快照和镜像有什么区别？**

快照是某一时间点对云硬盘的数据备份，适合定期备份和重大操作前保护数据；镜像是云服务器软件配置的模板，适合批量部署和系统迁移，没有定期创建功能。
